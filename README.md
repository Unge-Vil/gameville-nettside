# GameVille

Offisiell nettside for GameVille – en gratis, åpen møteplass for data- og gaminginteressert ungdom i Haugesund.

## Lokal utvikling

```bash
npm install
npm run dev
```

Nettsiden åpnes på `http://localhost:3000`.

## Produksjon og Coolify

Prosjektet inkluderer en `Dockerfile` og kan kobles direkte til Coolify fra GitHub. Tjenesten lytter på port `3000`.

## Planlagt

Eventkalender fra LANhub kobles på når API-tilgang er tilgjengelig.
